# Independent portfolio audit

Date: 2026-08-25. This review was performed against the rendered local site, the V1 archive, the CV, project repositories and available media. It supersedes assumptions in the original V2 design notes where the implementation has since changed.

## Perspective audit

- **Recruiter (20–30 seconds):** The hero communicates role, location, positioning, production scale and a next action immediately. The previous version was already strong here. The main risk was that animated counters briefly showed false values, so all proof figures are now static.
- **Hiring manager:** The flagship work has clear ownership and outcomes, but three identical traces made projects merge together. Job Agent now uses an exact public regression-test artifact, and QueLess shows a real customer workflow.
- **Senior AI/software engineer:** Verification-first positioning is credible and specific. The public verifier fixture, source link, corrected test count and explicit operations detail make it easier to inspect rather than trust claims. Confidential Maxis work remains represented through architecture and decision logic, not fabricated screenshots.
- **Product/interaction designer:** The restrained palette, typographic hierarchy and one semantic use of orange are strong. Repetition and an equal-weight builds ledger flattened the rhythm. The new evidence formats create contrast while keeping the same visual language.
- **Normal visitor:** The headline is understandable without AI jargon, but the original page required too much reading before reaching a tangible product. The live merchant workflow now gives a concrete example of what the work feels like.

## KEEP

- Verification-first positioning: “checked before anyone sees the answer.”
- Paper/ink/orange visual system; orange continues to mean a check, rejection or primary action.
- The NL2SQL request trace, abstention scenario and progressive enhancement.
- Native engineering-note disclosures, semantic HTML, reduced-motion support and no framework dependency.
- Maxis metrics and the compact professional timeline.
- Naro and Exa as a quiet personal signature rather than pervasive decoration.

## REFINE

- Project storytelling: retain one signature trace for the flagship and one for adversarial evaluation, then switch evidence format for Job Agent.
- Independent builds: replace equal text rows with a featured real workflow and a smaller secondary evidence grid.
- Mobile wayfinding: show Work, Builds and CV; keep Experience and Contact in the document and desktop navigation without forcing five tiny links into 390px.
- Performance: poster-first, user-controlled video with `preload="none"`; no autoplay.

## REMOVE

- Metric count-in animation. It produced visually false proof values during capture and undermined the site’s trust premise.
- The third repeated trace. The concept was sound, but the repetition made distinct projects feel templated.
- The “Skills, as evidence” section. Project stacks, engineering notes, experience and the CV already provide the same information with stronger context.
- The equal-weight four-item builds ledger.

## ADD

- Exact public Job Agent verifier fixture: stored fact → unsupported claim → rejection, linked to source.
- Real QueLess customer screen recording covering cart, checkout, DuitNow payment and order tracking.
- Short Content Studio pipeline-output excerpt, paired with copy explaining the human publishing gate.
- A 32KB two-character Naro and Exa crew derived from the existing mascot assets. The characters move independently when visitors inspect production proof, and collapse into a dedicated touch-friendly strip on mobile.
- Explicit media captions and purpose, responsive device framing, poster frames and dimensions.
- Corrected Job Agent proof: 129 automated tests collected across 25 test files.

## Implementation priorities

1. Fix trust defects first: static proof metrics and accurate test counts in the page, CV and social card.
2. Replace repeated explanation with inspectable evidence.
3. Bring a tangible shipped product forward without exposing confidential employer work.
4. Improve mobile scan rhythm and remove redundant sections.
5. Verify every breakpoint, interaction, media state and external project destination in the browser.

## Remaining manual assets worth supplying

- One current, natural professional photograph (working, speaking or at an event is preferable to a formal cut-out headshot). It would make the site more human in the Experience or Contact area; it should not displace the proof-led hero.
- A redacted screenshot or 10–15 second recording of the production NL2SQL answer experience, only if Maxis approves it. The most useful sequence is question → generated chart/table → visible grounding or abstention state.
- A redacted evaluation report showing one adversarial failure becoming a regression case, if it can be shared without exposing internal schemas or data.
